# v0.7.0

## Network sockets and active client observability

- Export open network socket counters via `xui_open_sockets{protocol="tcp|udp"}` directly from the panel's environment status snapshot without extra network overhead.
- Export active online client count via `xui_online_clients` queried concurrently from the panel's client session API (`POST /panel/api/clients/onlines`).
- Query panel configuration, status, and client sessions in parallel under a shared timeout and request budget, maintaining sub-10ms collection latency with zero local cache.

## Resilient API collection and diagnostics

- Ensure independent panel sub-requests survive partial failures, gracefully exporting remaining valid metrics while recording discrete error details (`api_onlines`, `api_status`, `api_settings`) in structured warning logs.
- Soften maintenance policy and disclaimer to welcome community pull requests and bug reports while keeping expectations clear about informal support.

## Grafana dashboards

- Add **Online clients** stat panel to the Overview section displaying active user sessions.
- Add **Connection stats** time series panel to the Overview section tracking TCP and UDP socket trends with live values matching 3x-ui style.
- Compact **Balancers** and **Observed outbounds** status panels to optimize overview screen real estate without losing readability.
- Maintain full variable support and compatibility across both Modern (`v2`) and Classic (`v1`) Grafana dashboard schemas.
