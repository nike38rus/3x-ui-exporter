# v1.1.0

## Multi-node cluster and inbound metadata observability

3x-ui-exporter **v1.1.0** introduces comprehensive monitoring for multi-node 3x-ui clusters, rich inbound metadata enrichment, and updated Grafana dashboards.

---

### Key Capabilities

#### Connected Nodes Cluster Observability
- Export remote node availability via `xui_node_online{node="..."}` based on master panel heartbeat probes.
- Export round-trip network latency between master and remote nodes via `xui_node_latency_seconds{node="..."}`.
- Export remote Xray core daemon state (`xui_node_xray_state{node="...",state="running|stop|error"}`).
- Export node CPU and memory utilization percent (`xui_node_cpu_percent`, `xui_node_memory_percent`).
- Export remote node uptime in seconds (`xui_node_uptime_seconds`).
- Export node version metadata (`xui_node_info{node="...",xray_version="...",panel_version="..."}`).
- Strict Prometheus missing-data semantics: offline and unreachable nodes gracefully omit latency, CPU, memory, and uptime metrics rather than fabricating misleading zeros.

#### Inbound Metadata & Node Enrichment
- Export administrative inbound state (`xui_inbound_enabled`) enriched with human-readable remarks (`remark="..."`) and node association (`node="..."`).
- Transparent fallback: inbounds hosted on the master panel are assigned `node="local"`, remote inbounds map to their parent node names, and inbounds without remarks fallback safely to their tag.

#### Resilient API Collection & Request Budget
- Query remote node cluster inventory concurrently via `GET /panel/api/nodes/list` alongside panel status, settings, inbounds, and active client sessions under a shared deadline (`SCRAPE_TIMEOUT`).
- All 5 panel sub-requests execute in parallel with sub-10ms collection latency and zero cross-scrape caching.
- Diagnostic scrape gauge `xui_exporter_scrape_success{source="api"}` validates the contract across all panel sub-endpoints, recording operation errors (`api_nodes`, `api_inbounds`, `api_status`, `api_onlines`, `api_settings`) in structured logs.

---

### Updated Grafana Dashboards

- **Overview Section**: Added **Connected nodes** indicator stat panel (`X / Y` online/total) matching the style of Balancers and Observed outbounds.
- **Dedicated Connected Nodes Row**:
  - **Availability history**: State timeline tracking remote node uptime and offline incidents over time.
  - **Node latency**: Time series tracking round-trip ping to remote VPS instances.
  - **Node inventory**: Comprehensive status table reporting Xray core state, uptime, inbound count, and software versions.
  - **Node resources**: Time series tracking CPU and RAM utilization across cluster nodes.
- **Inbounds Row**: Updated Throughput and Traffic distribution panels to display human-readable remarks and parent nodes, with added Administrative state timeline.
- Full parity maintained across both Modern (`v2`) and Classic (`v1`) Grafana dashboard schemas.
