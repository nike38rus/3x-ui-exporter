First public release of the 3x-ui Prometheus exporter.

## Features

- Fresh, synchronous collection from the 3x-ui settings API, Xray gRPC and expvars; no polling cache or alternate-source fallback.
- Inbound/outbound traffic, balancer target selection and structural outbound availability, ordinary/burst observatory results, and Xray memory/GC metrics.
- Independent source status and timing. Missing measurements remain absent.
- Grafana dashboards in classic JSON and resource schema v2 formats.
- Static Linux amd64/arm64 binaries, SHA-256 checksums and an unprivileged multi-architecture container image.

## Run

Container: `ghcr.io/nike38rus/3x-ui-exporter:0.1.0`.

See the README for required panel API access, Xray services, Compose deployment and Prometheus configuration. Archives include the dashboards, documentation and license notices.

## Compatibility and limitations

Compatibility is experimental: live verification used Xray 26.10.10; panel API implementation was inspected in 3x-ui 3.10.0 and 3.10.2. Dashboards were exported from Grafana 13.2. Other versions are not guaranteed compatible.

Balancer availability describes resolution to a runtime outbound, not an internet connectivity probe. Random/roundRobin selection metrics are omitted unless an override is active. Dashboard quality scores and replacement counts are estimates, not Xray routing logs.
