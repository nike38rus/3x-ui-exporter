# v1.4.4

## Unified outbound health & selection timeline, deep-link navigation, and updated screenshots

3x-ui-exporter **v1.4.4** is a patch release combining outbound health and balancer selection into a single unified State Timeline panel, introducing direct section deep-linking from Overview cards, updating all dashboard screenshots (including a new Inbounds section screenshot), and adding a demo screenshot anonymization tool.

---

### Features & Improvements

#### Grafana Dashboards (`classic` & `v2`)
- **Unified Outbound Health & Selection Timeline:** Combined separate health and balancer selection panels into a single unified State Timeline panel with dual-state semantic mapping:
  - **Active:** Currently selected outbounds routing traffic (bold saturated colors: green = UP, yellow = DEGRADED, red = DOWN).
  - **Standby:** Candidate outbounds in balancer reserve (soft muted colors: light-green = Ready, light-yellow = Degraded, light-red = Down).
  - Clear visual indicators for active overrides and fallback activation.
- **Section Deep-Linking (`drow`):** Replaced panel-isolating links with section deep-links (`drow=...`) across Overview cards (`drow=Exporter-stats`, `drow=Clients`, `drow=Connected-nodes`, `drow=Inbounds`, `drow=Outbounds`, `drow=Balancers-%2526-Observatory`), allowing one-click navigation directly to the corresponding expanded dashboard row.
- **Direct Outbound Color Pinning:** Fixed `direct` outbound series color to green in outbound throughput charts for visual consistency across scrapes.
- **Complete Dashboard Parity:** Fully synchronized panel configurations and layouts 1:1 across `grafana-3x-ui.classic.json` and `grafana-3x-ui.v2.json`.

#### Documentation & Demo Assets
- **Updated Dashboard Screenshots:** Refreshed all section screenshots in `docs/images/` to reflect the latest UI changes, including a new dedicated `inbounds.png` section screenshot.
- **Documentation Polish:** Added Inbounds section preview to `README.md` and corrected Table of Contents anchor links.
- **Dashboard Anonymizer Script:** Added `scripts/anonymize-dashboard.py` to sanitize private server details, tokens, and IPs before capturing demo assets.
