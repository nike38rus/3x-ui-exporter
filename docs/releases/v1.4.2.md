# v1.4.2

## Balancer candidate matching fix and Grafana dashboard refinements

3x-ui-exporter **v1.4.2** is a patch release fixing balancer candidate outbound selector matching and polishing the Grafana dashboards (Overview status indicators, Outbounds top-k time range anchoring, and empty state fallbacks).

---

### Bug Fixes

#### Exporter
- **Balancer candidate matching:** Trim whitespace from balancer selector prefixes, ignore empty selectors, and match candidates by both exact tag and prefix (`t == sel || strings.HasPrefix(t, sel)`), ensuring `xui_balancer_outbound_selected` candidates are properly exposed.

#### Grafana Dashboards (`classic` & `v2`)
- **Overview status indicators:** Refined source health and node connectivity cards with explicit error thresholds and added a dedicated Exporter version indicator.
- **Conditional node rows:** Added `$has_nodes_connected` variable to automatically collapse/hide cluster node panels on single-node setups.
- **Outbounds top-k query anchoring:** Anchored outbound throughput top-k range queries to the evaluation window end (`@ end()`) to eliminate series jitter across sliding windows.
- **Descriptive empty states:** Added contextual `noValue` fallbacks for optional features (`Outbound statistics disabled`, `Requires burstObservatory`, `Unknown`).
- **Dashboard parity:** Synchronized all thresholds, panel overrides, and queries across both `grafana-3x-ui.classic.json` and `grafana-3x-ui.v2.json`.
