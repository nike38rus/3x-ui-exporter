# v1.6.0

## Balancer egress operational health metric, dashboard egress timelines, and dependency updates

3x-ui-exporter **v1.6.0** is a minor release introducing the `xui_balancer_health` metric with recursive cascade resolution, updating Grafana dashboards with egress operational health timelines and fallback target visibility, automating third-party license synchronization for Dependabot, and updating core dependencies (Prometheus client and gRPC).

---

### Features & Improvements

#### Exporter
- **`xui_balancer_health` Metric:** Added a dedicated gauge metric (`xui_balancer_health{balancer="..."}`) evaluating the end-to-end operational egress health of each balancer by resolving its active target (whether primary, fallback, or override) against live Xray Observatory probes:
  - `0` = **Down** (structural failure, no route, or active target probe failed)
  - `1` = **Blind** (active target is valid but unmonitored / unprobed by Observatory)
  - `2` = **Up** (active target probe confirmed alive)
- **Recursive Cascade Resolution:** If a balancer's fallback or override routes to another balancer or outbound cascade, the operational health recursively follows the target chain to the final egress outbound.

#### Grafana Dashboards (`classic` & `v2`)
- **Overview Egress Health:** Migrated Overview balancer status cards to `xui_balancer_health`, reflecting real-world egress traffic delivery readiness (`Healthy`, `Blind`, `Down`).
- **Balancer Egress Health Timeline:** Added dedicated per-balancer operational health timelines in the Balancers & Observatory section.
- **Fallback Target Reveal:** Fallback panels now display the exact runtime outbound tag handling traffic when a fallback is active.
- **Streamlined Health Timelines:** Condensed and optimized outbound health timelines for clearer diagnostic scanning.

#### Maintenance, CI/CD & Dependencies
- **Core Dependency Updates:**
  - Upgraded `github.com/prometheus/client_golang` from `1.23.2` to **`1.25.0`**.
  - Upgraded `google.golang.org/grpc` from `1.84.0` to **`1.85.0`**.
  - Upgraded `docker/login-action` GitHub Action.
- **Automated License Synchronization:** Added automated workflow to keep `THIRD_PARTY_NOTICES.md` and `third_party_licenses/` in sync during Dependabot PRs.
- **Dashboard Validation on PR:** Enabled automated syntax and schema validation for Grafana dashboards on pull requests.
- **CI Performance:** Enabled native Go module caching and parallelized release verification.
