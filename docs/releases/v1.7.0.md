# v1.7.0

## Outbound outages timeline, uptime tracking, enhanced health visibility, and updated screenshots

3x-ui-exporter **v1.7.0** is a minor release introducing an Outbound Outages timeline panel, uptime percentage tracking, FAILED state visibility for standby balancer candidates, BLIND primary outbound support, resilient handling of unconfigured balancers and observatory, refreshed production dashboard screenshots, and Table of Contents GFM anchor fixes.

---

### Features & Improvements

#### Grafana Dashboards (`classic` & `v2`)
- **Outbound Outages Timeline:** Added a dedicated state timeline tracking individual outbound disruption events, distinguishing between alive, probe failure degraded, and hard down states.
- **Outbound Uptime Column:** Added an uptime percentage column in the Outbounds overview table calculating availability over the selected time range.
- **Standby Candidate Failure Visibility (`FAILED`):** In the Outbound Health & Selection timeline, reserve/standby candidates failing observatory probes are now explicitly highlighted in soft red (`FAILED`), alerting operators to degraded standby routes before they are activated.
- **BLIND Primary Support:** Improved health classification for primary outbounds that route traffic without active observatory monitoring (`BLIND`), ensuring transparent status across all selection roles.
- **Clean Fallback for Unconfigured Components:** Resolved card and chart rendering issues when balancers or Observatory are not configured in Xray, preventing misleading `No data` or error states.
- **Strict Bargauge Labels:** Enforced explicit value and category labels across horizontal bar gauges for clearer visual scanning.

#### Documentation & Demo Assets
- **Refreshed Dashboard Screenshots:** Updated all 8 dashboard screenshots in `docs/images/` (`overview`, `inbounds`, `outbounds`, `balancers`, `clients`, `nodes`, `xray`, `exporter`) reflecting the latest panel enhancements and layouts.
- **Anonymizer Enhancements:** Improved `scripts/anonymize-dashboard.py` to support deep anonymization of fallback tags and multi-node cluster topology.
- **Table of Contents Anchor Fixes:** Fixed GitHub Flavored Markdown (GFM) anchor slug resolution for headings with punctuation and slashes in `README.md`, and documented strict GFM anchor rules in `AGENTS.md`.
