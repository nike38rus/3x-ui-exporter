# v0.6.1

## Default exporter self-monitoring

- Enable standard Prometheus Go runtime (`go_*`) and process (`process_*`) metrics by default for the exporter itself.
- Remove `--include-exporter-metrics` and `INCLUDE_EXPORTER_METRICS` configuration toggles to streamline deployment and ensure out-of-the-box self-observability.
- Maintain optional `--collect-client-stats` flag (`COLLECT_CLIENT_STATS`, default: `false`) for per-user client metrics.

## Grafana dashboards

- Add **Exporter process memory** panel (`process_resident_memory_bytes` and `go_memstats_alloc_bytes`) to the *Exporter stats* section in both Classic and v2 dashboards.
- Add **Exporter CPU & Goroutines** panel (`process_cpu_seconds_total` and `go_goroutines`) to the *Exporter stats* section.
- Polish dashboard layout, field configurations, and styling for modern Grafana versions.

## Documentation

- Fully revamp `README.md` into comprehensive Prometheus exporter documentation.
- Add plain-language explanation, intuitive breakdowns, and interpretation guides for the outbound Quality Score.
