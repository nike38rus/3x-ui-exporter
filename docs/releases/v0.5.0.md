# v0.5.0

## Scratch container runtime and image hardening

- Switch container runtime to `scratch` with a statically linked Go binary, removing Alpine, shell and package manager dependencies.
- Add minimal unprivileged user definition (`nonroot`, UID 65532) and bundled CA certificates.
- Eliminate OS package vulnerabilities and reduce final image size to ~15 MB.
- Expand Makefile prepare target to create build cache subdirectories and add download target for clean checkouts.

## Structured logging and error reporting

- Report error messages in addition to error types on collection failure diagnostics, clarifying failures without leaking secrets.
- Add `--log-level` (`LOG_LEVEL`: debug, info, warn, error) and `--log-format` (`LOG_FORMAT`: text, json) configuration flags and environment variables.
- Add debug logging for successful source operations and completed requests.
- Tune HTTP connection pooling (`MaxIdleConns`, `MaxIdleConnsPerHost`, `IdleConnTimeout`) to prevent socket churn during concurrent collection.
