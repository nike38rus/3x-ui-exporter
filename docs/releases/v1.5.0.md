# v1.5.0

## Dedicated balancer state metric, dashboard routing refinements, and supply chain attestations

3x-ui-exporter **v1.5.0** is a minor release introducing the `xui_balancer_state` metric for atomic balancer operational mode monitoring, updating Grafana dashboards with refined balancer routing panels, optimizing multi-platform release builds with identical prebuilt binary packaging, and adding SLSA provenance and SBOM attestations to published container images.

---

### Features & Improvements

#### Exporter
- **`xui_balancer_state` Metric:** Added a dedicated gauge metric (`xui_balancer_state{balancer="..."}`) exposing the operational routing state of each configured balancer:
  - `0` = **Unavailable / No route** (structural failure, traffic is dropped)
  - `1` = **Fallback** (active fallback target in use)
  - `2` = **Primary** (healthy routing across primary candidate targets)
  - `3` = **Override** (manually overridden target active)

#### Grafana Dashboards (`classic` & `v2`)
- **Balancer Routing Timeline & Overview:** Migrated balancer overview cards and timeline panels to `xui_balancer_state`, clearly distinguishing between `Primary`, `Fallback`, `Override`, and `No route` states.
- **Concise Descriptions:** Streamlined panel descriptions across Overview, Balancers, and Observatory sections for clarity and fast diagnostics.

#### Build & Supply Chain Security
- **Identical Prebuilt Binary Packaging:** Reusable precompiled binaries are packaged directly into Docker images (`BINARY_SOURCE=prebuilt`), ensuring 100% binary identity between release archives and container images while reducing image build time from minutes to seconds.
- **Parallel Multi-Platform Matrix:** Multi-architecture image builds (`linux/amd64` and `linux/arm64`) build concurrently in GitHub Actions and merge into a multi-platform index via `docker buildx imagetools`.
- **BuildKit Go Caching:** Added cache mounts for `/go/pkg/mod` and `/root/.cache/go-build` in the Dockerfile.
- **SLSA Provenance & SBOM Attestations:** Enabled SLSA Build Level 3 provenance (`provenance: mode=max`) and Software Bill of Materials (`sbom: true`) attestations for all published container images on GitHub Container Registry (GHCR).
