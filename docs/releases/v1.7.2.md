# v1.7.2

## Isolated balancer derivation failures and RTT stability semantics clarification

3x-ui-exporter **v1.7.2** is a patch release isolating per-balancer derivation errors to ensure a routing error in one balancer does not discard metrics for other healthy balancers, adding regression tests, and clarifying cross-window RTT stability calculation nuances in documentation.

---

### Bug Fixes & Refactoring

#### Exporter Core
- **Per-Balancer Derivation Isolation:** Refactored `buildBalancerMetrics` to process each balancer independently (`buildSingleBalancerMetrics`). If an individual balancer encounters a configuration or resolution error (e.g. recursive routing loop or invalid cascade target), the exporter logs the failure and aggregates the error via `errors.Join`, but continues evaluating and exporting metrics for all other valid balancers.
- **Fault Isolation Tests:** Added `TestBalancerDerivationErrorPreservesOtherBalancers` to verify that an unresolvable balancer configuration leaves healthy balancers fully instrumented.

#### Documentation
- **Quality Score RTT Stability Semantics:** Clarified in `README.md` that RTT stability ($S$) evaluates quantiles over window-mean RTT snapshots (`xui_observatory_outbound_rtt_mean_seconds`), measuring sustained cross-window latency shifts, while intra-window jitter is tracked by RTT deviation metrics.
