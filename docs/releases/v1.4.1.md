# v1.4.1

## Security hardening, SHA-256 installer verification with automatic rollback, and concurrency fixes

3x-ui-exporter **v1.4.1** is a maintenance and security hardening release that adds SHA-256 checksum verification and automatic failure rollback to `install.sh`, isolates `--xui-insecure-skip-verify` strictly to panel requests, validates `--web.auth-healthz` startup configuration, and fixes a potential data race during concurrent gRPC scrapes.

---

### Bug Fixes & Security Hardening

#### Exporter & HTTP Server Security
- **Concurrent gRPC scrape safety:** Fixed a potential data race in `Exporter.readGRPC` where `GRPCCore.slowThreshold` could be mutated concurrently across overlapping scrapes when uninitialized.
- **Scoped TLS verification bypass (`--xui-insecure-skip-verify`):** Separated HTTP transports for the 3x-ui panel client and the Xray `expvars` client so `XUI_INSECURE_SKIP_VERIFY=true` applies strictly to panel API requests.
- **Fail-fast `--web.auth-healthz` validation:** Specifying `--web.auth-healthz` (`WEB_AUTH_HEALTHZ=true`) without Basic Auth or Bearer token credentials now fails at startup with a clear configuration error instead of silently leaving `/healthz` unprotected.

#### Automated `systemd` Installer (`install.sh`)
- **Mandatory SHA-256 checksum verification:** `install` and `update` now download `checksums_<version>.txt` and verify archive SHA-256 integrity (`sha256sum` / `shasum -a 256`) before extracting the binary.
- **Automatic rollback on failed `update` or `config-tls`:** Backs up the existing binary, configuration, and systemd unit before applying changes and automatically restores the previous working state if the service fails to start or fails the 3-source self-test.
- **Secret exposure protection:** Creates `/etc/3x-ui-exporter.env` under `umask 077` before writing secrets, redacts `WEB_BEARER_TOKEN` from console output, and passes the token to `curl` via stdin (`curl -K -`) during self-tests to avoid exposing credentials in process arguments (`ps`).
- **Strict self-test exit codes:** `install`, `update`, `config-tls`, and `status` now exit with a non-zero status whenever authentication checks or any of the three scrape sources (`api`, `grpc`, `expvars`) fail.
