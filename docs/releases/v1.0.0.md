# v1.0.0

## First General Availability (GA) Release

**3x-ui-exporter v1.0.0** marks the first stable, production-ready milestone for monitoring the **3x-ui** management panel and its underlying **Xray core**.

The exporter is built around a strictly synchronous, stateless pull model: zero local cache, zero background polling, and sub-5ms scrape latency with sub-25MB process memory footprint.

---

### Key Capabilities

#### Real-time Traffic Throughput
- Inbound and outbound traffic rates (`xui_inbound_traffic_bytes_total`, `xui_outbound_traffic_bytes_total`) with distinct `direction` metrics (`downlink` for client download, `uplink` for client upload).
- Optional per-client traffic statistics enabled via `--collect-client-stats`.

#### Client & Network Environment Activity
- Active online sessions count (`xui_online_clients`) queried concurrently via the panel's client session API.
- Open network sockets count (`xui_open_sockets{protocol="tcp|udp"}`) reported directly from the system environment without extra roundtrips.

#### Xray Balancers & Routing Visibility
- Active outbound targets, configured fallback statuses, and runtime overrides (`xui_balancer_outbound_selected`).
- Structural outbound availability (`xui_balancer_outbound_available`).

#### Observatory Latency & Health Probes
- Probe status, packet loss, and RTT mean/deviation statistics across observation windows.
- Outbound Quality Score (0–100) calculated directly in Grafana.

#### Process & Runtime Diagnostics
- Full Xray Go runtime observability: live heap allocations, reserved memory, GC cycles, and stop-the-world pause fractions.
- Panel and Xray binary versions (`xui_panel_info`, `xui_xray_info`) and daemon process state (`xui_xray_state`).
- Standard Go runtime (`go_*`) and process (`process_*`) self-metrics enabled by default.

### Included Dashboards & Examples

- **Pre-configured Grafana Dashboards**: Modern Grafana (v2 schema) and Classic (v1 schema) dashboards preloaded with Overview, Traffic, Balancers, Observatory, and Runtime panels.
