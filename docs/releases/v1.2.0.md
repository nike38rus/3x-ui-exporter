# v1.2.0

## Cluster traffic accounting, per-node online clients, and enhanced node telemetry

3x-ui-exporter **v1.2.0** adds cluster-wide cumulative inbound traffic accounting across all nodes, granular online client metrics per node (including local master panel matching), and major dashboard enhancements with fresh anonymized documentation screenshots.

---

### Key Capabilities

#### Cluster-Wide Inbound Traffic (`xui_inbound_bytes_total`)
- **Cross-node cumulative accounting:** Export cumulative inbound traffic across all nodes (`node="local"` and remote subordinate nodes) directly from the 3x-ui database.
- **Standard Prometheus dimensions:** Labels include `inbound`, `remark`, `node`, and `direction` (`uplink` / `downlink`).
- **True cluster visibility:** Solves the visibility limitation of Xray core `expvars`, which only measures the local master core; now traffic from all cluster nodes is fully monitored.

#### Per-Node Online Clients (`xui_node_online_clients`)
- **Session distribution:** Export active online client counts broken down by node (`node="..."`).
- **Local node session matching:** For the master panel (`node="local"`), active client emails from `POST /panel/api/clients/onlines` are correlated against local inbounds without making extra requests. Emits `0` when idle (actual measured state) and exact count when clients are connected.
- **Strict missing data contract:** Disconnected and offline remote nodes gracefully omit metrics rather than fabricating misleading zeros.

---

### Updated Grafana Dashboards

- **Connected Nodes -> Inventory Table:** Added **Online clients** column to inspect active sessions alongside Xray state, uptime, inbound counts, and software versions.
- **Connected Nodes -> Node Throughput:** Added dedicated Time Series panel for remote node network throughput (bits/sec), with automatic suppression of offline nodes (`and on (node) (xui_node_online == 1)`).
- **Connected Nodes -> Traffic Volume:** Added Bar Gauge panel showing total bytes transferred per remote node over the dashboard time range (`$__range`).
- **Inbounds -> Traffic Distribution Bar Gauge:** Fixed long-standing bar scaling issue where bars appeared as thin slivers by removing legacy `fieldMinMax: true` and explicitly setting `Min: 0`.
- **Documentation Screenshots:** Completely refreshed all 10 high-resolution screenshots in `docs/images/` with clean anonymized entity placeholders (`node-1`, `inbound-1`, `outbound-1`, `balancer-1`) and fully sanitized local addresses.
- Full feature and query parity maintained across both Modern (`v2`) and Classic (`v1`) dashboard formats.
