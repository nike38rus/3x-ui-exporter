# v1.3.0

## Client lifecycle accounting, unified Balancers & Observatory, and modernized Outbounds traffic

3x-ui-exporter **v1.3.0** introduces cluster client lifecycle metrics (`xui_client_count`), standardizes client domain telemetry (`xui_client_online`), adds a dedicated **Clients** dashboard section, consolidates Balancers and Observatory into an integrated quality table, and modernizes outbounds traffic distribution.

---

### Important Notice: Classic Grafana Dashboard Deprecation

> [!WARNING]
> **Deprecation Notice:** `grafana-3x-ui.classic.json` will no longer be maintained in future releases. Starting with the next major release (v2.0.0), only the modern Grafana Scenes schema (**`grafana-3x-ui.v2.json`**) will be supported. Users are encouraged to migrate to Grafana 11+ or import `grafana-3x-ui.v2.json`.

---

### Key Capabilities

#### Client Lifecycle & Account Monitoring (`xui_client_count`)
- **Lifecycle state tracking:** Export client accounts categorized by mutually exclusive states:
  - `state="active"`: Enabled client accounts within data and validity limits.
  - `state="disabled"`: Administratively disabled client accounts.
  - `state="expired"`: Accounts past their expiration timestamp (`expiry_time`).
  - `state="depleted"`: Accounts that exceeded their total byte quotas (`up + down >= total`).
- **Subscription deduplication:** Accounts sharing the same email/identifier across multi-inbound subscriptions are deduplicated, reflecting actual user count rather than database row duplicates.

#### Standardized Online Client Sessions (`xui_client_online`)
- **Metric alignment:** Active cluster online client sessions are exported as `xui_client_online` (conforming to the `xui_client_*` domain namespace).

### Dashboard Enhancements

#### New Clients Section
- **Account status overview:** High-level gauge showing total clients, active accounts, and current online sessions.
- **Active sessions history:** Time series tracking online client concurrency over time.

#### Consolidated Balancers & Observatory
- **Outbound quality & health table:** Combined single overview table replacing disconnected panels:
  - Computed Outbound **Quality Score** (0–100) combining probe success, latency, and speed.
  - Live health state (`UP` / `DEGRADED` / `DOWN`).
  - Current RTT, P95 RTT, and jitter deviation.
  - Probe success rate and alive uptime.
- **Dynamic balancer tabs (v2):** Declarative repeated tabs per balancer in `grafana-3x-ui.v2.json`.
- **Eliminated broken variables:** Removed obsolete `${outbound}` variable references that caused `No data` issues.

#### Modernized Outbounds Traffic Section
- **3-Query architecture:** Separates `direct` traffic, top 6 proxy tunnels (`topk 6` > 10 MB), and aggregates the remaining proxies into `others`.
- **Volume parity:** 100% volume parity between the Outbound throughput time series, Traffic distribution bar gauge, and Traffic routing donut chart (`Proxy` vs `Direct`).

#### Documentation & Media
- Refreshed all screenshots in `docs/images/` with clean `.png` assets using strictly anonymized numbered entities (`balancer-1`, `outbound-1`, `inbound-1`, `node-master`).
