# v1.6.1

## Balancer empty target handling and blackhole fallback resolution

3x-ui-exporter **v1.6.1** is a patch release fixing balancer metric collection when Xray reports an empty principle target tag and ensuring blackhole outbounds and fallbacks resolve to operational down status.

---

### Bug Fixes & Improvements

#### Balancer & gRPC Collection
- **Empty Principle Target Tag Resilience:** When Xray's `RoutingService.GetBalancerInfo` returns an empty string in `PrincipleTarget.Tag` (observed when all primary targets fail or when transitioning to fallback), the exporter now skips the empty tag rather than rejecting the response as a contract error. This ensures balancer metrics remain valid, allowing `xui_balancer_state` to transition to fallback (`1`) and selecting the configured `fallbackTag`.
- **Blackhole Outbound & Fallback Health:** Explicitly resolved outbounds with protocol `blackhole` as `health = 0` (Down) instead of treating them as unmonitored / blind (`1`). Balancers routing or falling back to a `blackhole` outbound now correctly report `xui_balancer_health{balancer="..."} = 0`.
