# v1.4.3

## Grafana dashboard IEC units standardization, PromQL simplification, and fallback parity

3x-ui-exporter **v1.4.3** is a patch release standardizing Grafana dashboard display units to IEC standards, simplifying PromQL queries by eliminating redundant scrape guards, and unifying empty-state fallbacks across classic and v2 dashboards.

---

### Improvements & Fixes

#### Grafana Dashboards (`classic` & `v2`)
- **IEC Units Standardization:** Standardized throughput rate panels to `binbps` (Bits/sec IEC: Kibit/s, Mibit/s) and cumulative data volume panels to `bytes` (Bytes IEC: KiB, MiB, GiB).
- **PromQL Simplification:** Removed redundant `and on() (xui_exporter_scrape_success... == 1) and on() (up... == 1)` guards from traffic, balancer, and observatory queries to preserve native Prometheus missing-data semantics and reduce query evaluation cost.
- **Unified Fallback States:** Replaced ambiguous `No data` placeholders with contextual fallbacks (`Unknown`, `Inbound statistics disabled`, `Outbound statistics disabled`).
- **Complete Dashboard Parity:** Synchronized all 47 panels 1:1 across both `grafana-3x-ui.classic.json` and `grafana-3x-ui.v2.json`.
